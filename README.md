# 🤖 CrewAI Multi-Agent Project

A hands-on project exploring Multi-Agent Systems using CrewAI.

This project is part of my AI Engineering journey, where I am learning how multiple AI agents can collaborate to complete tasks through defined roles and workflows.

## 🚀 Technologies

- Python
- CrewAI
- CrewAI Tools
- Jupyter Notebook

## 📌 Project Overview

This project demonstrates the use of CrewAI to build a multi-agent workflow.

The project focuses on:
- Creating AI agents with specific roles
- Defining tasks for each agent
- Organizing agents into a collaborative workflow
- Using tools to enhance agent capabilities
